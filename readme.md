# 📦 4KHD Auto Downloader (Flaskfarm Plugin)

4KHD.com에서 등록한 키워드와 일치하는 게시물을 자동으로 감지하여 이미지를 ZIP 파일로 다운로드하는 Flaskfarm 플러그인입니다.

## ✨ 주요 기능

### 🔑 키워드 기반 자동 다운로드
- 키워드 등록 시 해당 키워드가 포함된 새 게시물을 자동 감지
- 대소문자 구분 없이 게시물 제목에서 매칭
- 최대 5개 동시 다운로드 지원

### 📂 스마트 중복 관리
- 다운로드 완료된 게시물은 DB에 기록하여 자동 스킵
- 히스토리에서 개별 항목 삭제 → 다음 스캔 시 재다운로드
- 강제 재다운로드 기능 (파일 덮어쓰기)

### 🕐 과거 자료 탐색
- 키워드별 "과거 포함" 옵션 활성화 시 이전 게시물까지 전체 스캔
- 완료 후 자동으로 "신규만" 모드로 전환

### 🔔 디스코드 알림
- 다운로드 완료/실패 시 디스코드 웹훅으로 알림
- Embed 형태로 제목, 키워드, 이미지 수 등 상세 정보 제공

## 📋 메뉴 구성

| 메뉴 | 기능 |
|------|------|
| **키워드** | 키워드 등록/삭제, 활성화 토글, 과거 포함 토글, 수동 스캔 |
| **히스토리** | 다운로드 내역 조회, 필터, 재다운로드, 기록 삭제, 전체 초기화 |
| **설정** | 사이트 주소, 다운로드 경로, 스캔 주기, 디스코드 웹훅 |
| **로그** | 실행 로그 확인 |

## ⚙️ 설정

| 항목 | 설명 | 기본값 |
|------|------|--------|
| 4KHD 주소 | 사이트 주소 (자동 탐지 지원) | https://gghh.uk |
| 다운로드 경로 | ZIP 저장 위치 | ./downloads/ff_4khd_auto |
| 이미지 프록시 | 프록시 사용 여부 | ON |
| 자동 스캔 | 자동 스캔 활성화 | OFF |
| 스캔 주기 | 분 단위 (최소 5분) | 30분 |
| 동시 다운로드 | 최대 동시 다운로드 수 | 5 |
| 디스코드 Webhook | 알림 URL (비워두면 비활성) | - |

## 🚀 설치

1. `ff_4khd_auto` 폴더를 Flaskfarm 플러그인 디렉토리에 복사
2. Flaskfarm 재시작
3. 설정에서 4KHD 주소 및 다운로드 경로 확인
4. 키워드 메뉴에서 원하는 키워드 등록
5. 설정에서 자동 스캔 활성화

## 📌 의존성

- `cloudscraper` — Cloudflare 우회
- `beautifulsoup4` — HTML 파싱
- `lxml` — XML/HTML 파서
- `Pillow` (선택) — 이미지 JPG 변환

> 의존성은 플러그인 로드 시 자동 설치됩니다.
